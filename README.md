# Pleazyng Homebrew tap

Official SnapeTech tap for [Pleazyng](https://github.com/snapetech-org/PlezyNG).

The Pleazyng release workflow publishes `Casks/snapetech-pleazyng.rb` here only after the macOS release is signed with Developer ID, notarized, and verified against its attested checksums. No Cask has been published yet.

After the first qualified Cask is published, install with:

```sh
brew install --cask snapetech-org/pleazyng/snapetech-pleazyng
```

Support and release reports: https://github.com/snapetech-org/PlezyNG/issues
